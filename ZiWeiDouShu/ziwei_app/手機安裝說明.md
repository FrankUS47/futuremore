# 紫微排盤 手機離線版 安裝說明

不需要 App Store、不需要 Google Play。原理是 PWA(網頁式 App):**第一次連網打開時,手機會把整個程式存起來;之後飛航模式、沒有網路也能用。**

排盤、農曆換算、解說全部在手機上計算,不會把任何生辰資料傳出去。

---

## 步驟 1:把資料夾放到網路上(只做一次,免費)

手機要「加入主畫面」並離線使用,網頁必須是 https 網址。選一個免費服務,把**這個資料夾裡的全部檔案**(index.html、css、js、icons、sw.js、manifest.webmanifest …)上傳即可:

- **GitHub Pages**:建立新的 repository → Add file → Upload files(上傳資料夾「裡面」的全部內容)→ Settings → Pages → Branch 選 main、資料夾選 `/ (root)` → 儲存。幾分鐘後得到 `https://你的帳號.github.io/repository名稱/`
- **Cloudflare Pages / Netlify**:建立專案後選「直接上傳 / Drag and drop」,把資料夾拖進去即可。

> 網址可以設為私人不公開;沒有人知道網址就不會被找到。

## 步驟 2:安裝到手機(只做一次)

**iPhone(用 Safari)**
1. 用 Safari 開啟上面的網址,等畫面最下方出現「已可離線使用 ✓」。
2. 點下方「分享」按鈕 → 「加入主畫面」→ 「新增」。
3. 之後從主畫面圖示開啟,開飛航模式也能用。

**Android(用 Chrome)**
1. 用 Chrome 開啟網址,等畫面最下方出現「已可離線使用 ✓」。
2. 點頁面底部的「安裝到手機」按鈕(或右上角選單 →「安裝應用程式」/「加到主畫面」)。
3. 之後從主畫面或應用程式列表開啟,離線可用。

## 想知道有沒有成功離線?

打開 App,最下方一行會顯示「版本 … · 已可離線使用 ✓」就代表檔案已存在手機裡。

## 更新到新版

收到新版資料夾後:整個資料夾替換、重新上傳(舊檔案不要混用),手機連網開啟一次,看到「已下載新版」後關掉再開即可。
(自己改過程式的話,請把 `js/version.js` 裡的版本號 +1,否則手機不會更新。)

---

## 不想架網站:單一檔案版(僅 Android 可行)

`dist/ziwei_single.html` 是把所有程式合併成一個檔案,不需要網路也不需要其他檔案。

- **Android**:把這個檔案傳到手機(LINE、雲端、USB 都可以),在「檔案」App 裡點開,選用 Chrome 開啟即可使用。這種方式沒有「加入主畫面」功能,但可以把它加入書籤。
- **iPhone**:沒有 App Store 的 App 就無法直接開啟本機 HTML 檔(「檔案」App 的預覽不會執行網頁程式)。iPhone 請用上面的 PWA 方式。

## 匯出文字檔

手機上按「另存純文字檔」會跳出系統的分享面板,可選「儲存到檔案」「傳到 LINE」等。電腦則直接下載。

## 已知限制

- 日期範圍:農曆資料只涵蓋 1900~2030 年。
- iPhone 若長時間(約數週)完全沒開過這個 App 且手機儲存空間很吃緊,系統可能清掉快取;只要再連網開一次就會重新存好。
